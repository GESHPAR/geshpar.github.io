# GESHPAR

مقالات و راهنمای مشاوره خانواده | Family Counseling Articles & Guides

🌐 وب‌سایت: <https://geshpar.com>

## درباره
GESHPAR یک وب‌سایت استاتیک فارسی در حوزهٔ مشاورهٔ خانواده است؛ شامل مقالات، راهنماهای تخصصی (از جمله راهنمای مشاورهٔ زوجی) و صفحهٔ تماس.

## بخش‌های سایت
- **blog/** — مقالات
- **guides/marriage-therapy-guide/** — راهنمای مشاورهٔ زوجی
- **contact/** — صفحهٔ تماس

## ابزارهای خودکارسازی (Python)
- `html_generator.py` — تولید صفحه‌های HTML از پایگاه محتوا
- `auto_linker.py` — لینک‌سازی داخلی خودکار
- `auto_cleanup.py` — پاک‌سازی و حذف فایل‌های تکراری
- `update_inventory.py` — به‌روزرسانی فهرست محتوا
- `run_bot.py` — اجرای ربات و آمارگیری

## اجرای ابزارها
```bash
python html_generator.py
python auto_linker.py
python update_inventory.py
```
